# Paper library metadata

Use only values supported by the paper, its authoritative landing page, or the
user.

- `status`: one of `interested`, `to-read`, `reading`, `read`, or `archived`.
- `priority`: `low`, `normal`, or `high`; this represents the user's attention,
  not paper quality.
- `fields`: broad disciplines, such as `electromagnetics` or
  `machine-learning`.
- `topics`: narrower paper-specific subjects, such as
  `metasurface-beamforming` or `sim-to-real-transfer`.
- `methods`: techniques actually used by the paper, not methods only mentioned
  in related work.
- `tags`: personal workflow or cross-cutting labels.

Labels are lower-case and hyphenated. Prefer an existing synonymous label over
creating a new spelling.

A complete reading note should include the paper's summary, contributions,
claims and evidence with source locations, methods, results, limitations,
questions, connections, new hypotheses, and a dated reading log. Keep new
hypotheses explicitly separate from source evidence.
