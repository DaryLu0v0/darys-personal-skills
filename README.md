# Dary's Personal Skills

Private monorepo for Dary's reusable Codex skills, their supporting tools, and validation suites.

## Categories

- [`overleaf-related/`](overleaf-related/) — scientific LaTeX review, Grammarly-assisted analysis, and supervised Overleaf review-panel workflows.
- [`codex-pet-ping/`](codex-pet-ping/) — Windows Need Vision ping screenshot questions answered by the existing desktop pet; built on [lolPing](https://github.com/darrenprx/lolPing), with workflow inspiration from [super-ping](https://github.com/norvancc/super-ping).

Each skill keeps its instructions, supporting references, implementation, and tests together so it can be audited before installation or use.
